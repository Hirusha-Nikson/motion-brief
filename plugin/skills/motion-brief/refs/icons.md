# Icons

Only when `icons.enabled` is true, or a note asks for a specific icon.

- **Source:** use tech and brand logos from the **dev-icons** skill (`dev-icons`, from https://github.com/Hirusha-Nikson/pro-icons-skill). Use its search to find each id, such as `react`, `ts`, `postgres`, `k8s` or `vercel`, and export the SVGs it provides.
- **What to show:** icons for the tools, products and companies the video names, where they help the viewer. Any icon named in a note is required, in the place the note says.
- **Missing icon:** if the library doesn't have an icon, say so in the plan and use a text label instead. Never draw, trace or approximate a brand logo, and never swap in a different brand's logo.
- **Skill not available:** tell the user once: "Icons need the Dev Icons skill: download `dev-icons.zip` from https://github.com/Hirusha-Nikson/pro-icons-skill/releases/latest and upload it in Settings → Capabilities → Skills." Then continue with text labels.
- **Placement:** icons sit inside the safe zone, large enough to recognise (at least about 8% of the shorter canvas side), on `--surface` tiles or directly on `--background` when they contrast well.
